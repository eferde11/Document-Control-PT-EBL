# Document Control - PT Energi Batubara Lestari (ISO 9001, 14001, 45001)

Aplikasi Web **Document Control System** yang dirancang khusus untuk PT Energi Batubara Lestari guna mengelola struktur 12 folder dokumen implementasi Sistem Manajemen Terintegrasi (Mutu, Lingkungan, dan K3) sesuai standar ISO 9001, ISO 14001, dan ISO 45001.

---

## 📁 12 Modul Folder Utama
1. **SK Tim ISO & SNI**
2. **Kebijakan Mutu K3L & Pencapaian**
3. **Proses Bisnis**
4. **Isu Eksternal dan Internal**
5. **Kebutuhan dan Harapan Stakeholder**
6. **Identifikasi Peraturan Perusahaan dan Perundangan Terkait**
7. **HIRADC dan IBPR**
8. **Struktur Organisasi dan Jobdesc**
9. **Manual Mutu K3L**
10. **Sertifikat Training AW dan IA**
11. **Dokumen Departemen - Site**
12. **Dokumen Departemen - HO**

## 🚀 Cara Upload ke GitHub

Ikuti langkah-langkah di bawah ini untuk mengunggah kode aplikasi ini ke repository GitHub Anda:

1. **Buat Repository Baru di GitHub**:
   - Masuk ke akun [GitHub](https://github.com/) Anda.
   - Klik tombol **New** di pojok kanan atas atau kunjungi [github.com/new](https://github.com/new).
   - Beri nama repository Anda (misal: `pt-ebl-document-control`).
   - Pilih visibilitas **Public** atau **Private**.
   - **Jangan** centang opsi "Add a README file" (karena file README sudah tersedia di atas).
   - Klik **Create repository**.

2. **Simpan File Kode di Komputer**:
   - Salin kode dari file `index.html` di bawah dan simpan di komputer dengan nama persis `index.html`.
   - Simpan file panduan ini dengan nama `README.md` di folder yang sama.

3. **Upload melalui Terminal / Command Prompt**:
   Buka terminal di dalam folder penyimpanan file Anda, lalu ketik perintah berikut:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Document Control PT Energi Batubara Lestari ISO 9001 14001 45001"
   git branch -M main
   git remote add origin https://github.com/USERNAME/NAMA-REPO-ANDA.git
   git push -u origin main
   ```
   *(Ganti `USERNAME/NAMA-REPO-ANDA` dengan URL repository GitHub Anda)*

4. **Alternatif (Upload Manual lewat Web Browser)**:
   - Buka halaman repository GitHub Anda.
   - Klik tulisan **"upload an existing file"**.
   - Tarik dan letakkan (*drag & drop*) file `index.html` dan `README.md`.
   - Klik **Commit changes**.

## 🌐 Publikasi Online Gratis (GitHub Pages)
Anda dapat langsung menjadikan aplikasi ini website online yang bisa diakses publik:
1. Masuk ke tab **Settings** di repository GitHub Anda.
2. Di menu sebelah kiri, klik **Pages**.
3. Pada bagian *Build and deployment*, ubah *Branch* dari `None` menjadi **main** (folder `/ (root)`), lalu klik **Save**.
4. Tunggu 1 menit, link website aplikasi QHSE PT Energi Batubara Lestari Anda akan muncul secara otomatis!
