Perubahan belum dipublikasikan

Data website sudah diperbarui sejak Anda mulai mengubah di browser ini. Unduh perubahan Anda terlebih dahulu, lalu buang perubahan lokal agar mengikuti data terbaru.

Mempublikasikan perubahan ke link website

  1. Klik Unduh data.json.
  2. Buka repositori GitHub, lalu Add file > Upload files dan unggah data.json ke folder yang sama dengan index.html (timpa file lama).
  3. Klik Commit changes. Setelah 1 sampai 2 menit, semua pengguna melihat data terbaru di link yang sama.

Mengirim perubahan ke Document Controller

  1. Klik Unduh perubahan.
  2. Kirim berkas perubahan-departemen.json ke Document Controller.
  3. Setelah Document Controller mempublikasikan, klik Buang perubahan di browser ini agar data Anda mengikuti website.

Tentang PT Energi Batubara Lestari

Aplikasi Document Control - PT Energi Batubara Lestari dirancang khusus untuk mengakomodasi 12 struktur folder standar manajemen ISO terintegrasi:

  • ISO 9001:2015 (Sistem Manajemen Mutu)
  • ISO 14001:2015 (Sistem Manajemen Lingkungan)
  • ISO 45001:2018 (Sistem Manajemen K3)

Dibangun dengan arsitektur modern Single-File Web App, siap di-deploy ke GitHub Pages atau Vercel.
