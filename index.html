Tentang PT Energi Batubara Lestari

Aplikasi Document Control - PT Energi Batubara Lestari dirancang khusus untuk mengakomodasi 12 struktur folder standar manajemen ISO terintegrasi:

  • ISO 9001:2015 (Sistem Manajemen Mutu)
  • ISO 14001:2015 (Sistem Manajemen Lingkungan)
  • ISO 45001:2018 (Sistem Manajemen K3)

Dibangun dengan arsitektur modern Single-File Web App, siap di-deploy ke GitHub Pages atau Vercel.
